# Mordi Media Downloader

בוט Telegram אישי להורדת מדיה ציבורית ומורשית:

- וידאו ואודיו דרך `yt-dlp`, כולל המחלץ הכללי לאתרים עם וידאו מוטמע.
- תמונות, גלריות ומדיה של פוסטים דרך `gallery-dl`.
- שכבת גיבוי לדפי HTML ולקישורים ישירים של תמונה, וידאו או אודיו.
- תור הורדות, משוב התקדמות, בחירת איכות ותגובה לקישור המקורי.
- הגנות מפני כתובות מקומיות, הגבלת גודל, מספר קבצים, זמן וריבוי הורדות.
- האצת HTTP בעזרת `aria2c` עם עד שמונה חיבורים.
- MP3 ב־128k או 320k עם כותרת, יוצר ותמונת עטיפה מוטמעים כשזמינים.
- הורדת וידאו 720p ללא קול או עם כתוביות עברית/אנגלית מוטמעות.
- העדפת H.264/AAC לקבלת תאימות טובה יותר במכשירים וב־Telegram.
- מסלול YouTube עצמאי דרך Innertube, ולאחריו GitHub Actions חינמי כשרת
  גיבוי בעל כתובת יציאה נפרדת כאשר Render נחסם.

אין אפשרות להבטיח תמיכה בכל אתר: תוכן פרטי, DRM, CAPTCHA, התחברות,
חסימות נגד בוטים או עמודים שמייצרים את המדיה רק לאחר הרצת JavaScript עשויים
לא להיות נגישים.

## הגדרות עיקריות

- `MAX_FILE_SIZE_MB` — גודל מרבי לקובץ בודד.
- `MAX_MEDIA_ITEMS` — מספר מרבי של פריטים מקישור אחד (ברירת מחדל 15).
- `MEDIA_CONCURRENCY` — מספר הורדות מדיה מקבילות (ברירת מחדל 3).
- `TEMP_TTL_MINUTES` — זמן תפוגה לבחירת פורמט.

לשימוש אישי ולימודי בלבד, ורק בתוכן שבבעלות המשתמש או שניתן אישור לשמור.
