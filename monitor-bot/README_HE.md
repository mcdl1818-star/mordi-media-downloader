# בוט מעקב אחרי יוצרי תוכן

הבוט מקבל קישור לפרופיל/ערוץ ב־YouTube, Instagram, Facebook, TikTok או X,
שומר את הפרסומים הקיימים כנקודת התחלה, ובכל סריקה שולח ל־Telegram רק פרסומים חדשים.

## הפעלה

1. צור בוט חדש אצל `@BotFather` והעתק את ה־token.
2. העתק `.env.example` אל `.env` ומלא `TELEGRAM_BOT_TOKEN` ו־`ALLOWED_TELEGRAM_USER_ID`.
3. ודא ש־`yt-dlp`, `gallery-dl` ו־`ffmpeg` מותקנים, או הפעל עם Docker:

```powershell
docker compose up -d --build
```

ללא Docker:

```powershell
npm start
```

## התנהגות ומגבלות

- ברירת המחדל היא בדיקה כל 10 דקות. אפשר להגדיר `CHECK_INTERVAL_MINUTES=60`.
- `SEND_MODE=video` מנסה להוריד ולשלוח את הסרטון; אם ההורדה נחסמת או שהקובץ גדול
  מדי, נשלחת התראה עם קישור כדי שלא לפספס את הפרסום.
- במחשב Windows הנוכחי אפשר להפעיל את `start-monitor.cmd`. משימת האתחול
  `Mordi Creator Monitor` מפעילה אותו אוטומטית בכל כניסה למשתמש.
- יש לשמור את תיקיית `data` על דיסק קבוע. מחיקתה מאפסת את נקודת ההתחלה.
- חשבונות פרטיים אינם נתמכים. פלטפורמות עשויות לדרוש `cookies.txt` ואף לחסום שרת
  לאחר ריבוי בקשות. לכן אין אפשרות להבטיח 100% באמצעות ממשק חינמי ולא רשמי.
- כל כתובת נסרקת בנפרד ובאופן סדרתי, כדי לצמצם חסימות וקצב בקשות.
